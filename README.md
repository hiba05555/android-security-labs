# Android Security Labs

Collection de labs pratiques de sécurité mobile Android couvrant
l'analyse statique, dynamique, le reverse engineering et le bypass
de protections.

## Structure des labs

| # | Thème | Labs |
|---|-------|------|
| 01 | Environment Setup | Lab 01 |
| 02 | Network Traffic | Labs 03, 15, 16 |
| 03 | Static Analysis | Labs 04, 06 |
| 04 | Dynamic Analysis | Labs 07, 09 |
| 05 | Rooting | Labs 02, 08 |
| 06 | Frida & Hooking | Labs 10, 11, 12, 13, 14 |
| 07 | Reverse Engineering & CTF | Labs 05, 17, 18, 19 |

## Avertissement légal

Tous ces labs sont réalisés dans un environnement isolé
et contrôlé, à des fins éducatives uniquement.

## Outils principaux

`JADX` `MobSF` `Frida` `Objection` `Burp Suite` `Drozer` `Medusa`
